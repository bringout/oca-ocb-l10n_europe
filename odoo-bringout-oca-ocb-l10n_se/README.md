# Sweden - Accounting


Swedish Accounting
------------------

This is the base module to manage the accounting chart for Sweden in Odoo.
It also includes the invoice OCR payment reference handling.
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_se
```

## Dependencies

- account
- base_vat
