# Italy - Accounting


Piano dei conti italiano di un'impresa generica.
================================================

Italian accounting chart and localization.
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_it
```

## Dependencies

- account
- base_iban
- base_vat
- account_edi_ubl_cii
