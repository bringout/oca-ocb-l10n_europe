# Pakistan - Accounting


Pakistan Accounting Module
=======================================================
Pakistan accounting basic charts and localization.

Activates:

- Chart of Accounts
- Taxes
- Tax Report
- Withholding Tax Report
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_pk
```

## Dependencies

- account

## Source

- Repository: https://github.com/OCA/OCB
