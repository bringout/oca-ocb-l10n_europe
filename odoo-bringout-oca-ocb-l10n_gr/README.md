# Greece - Accounting


This is the base module to manage the accounting chart for Greece.
==================================================================

Greek accounting chart and localization.
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_gr
```

## Dependencies

- account
- base_iban
- base_vat
- account_edi_ubl_cii
