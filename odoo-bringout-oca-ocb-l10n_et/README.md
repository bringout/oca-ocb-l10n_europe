# Ethiopia - Accounting


Base Module for Ethiopian Localization
======================================

This is the latest Ethiopian Odoo localization and consists of:
    - Chart of Accounts
    - VAT tax structure
    - Withholding tax structure
    - Regional State listings
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_et
```

## Dependencies

- account
