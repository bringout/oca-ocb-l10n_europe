# France - Peppol integration with Chorus Pro


Add support to fill three optional fields used when using Chorus Pro, especially when invoicing public services.


## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_fr_facturx_chorus_pro
```

## Dependencies

- account
- account_edi_ubl_cii
- l10n_fr_account
