# Norway - Accounting

This is the module to manage the accounting chart for Norway in Odoo.

Updated for Odoo 9 by Bringsvor Consulting AS <www.bringsvor.com>


## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_no
```

## Dependencies

- base_iban
- base_vat
- account
