# Ireland - Accounting


This is the base module to manage the accounting chart for Republic of Ireland in Odoo.
    

## Installation

```bash
pip install odoo-bringout-oca-ocb-l10n_ie
```

## Dependencies

- account
- base_iban
- base_vat
